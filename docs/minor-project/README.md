# Minor Project Capstone Submission

**Title**: AgriChain AI: An AI-Powered Kinnow Quality Inspection and Cold-Chain Management Platform for Punjab

This documentation package contains the comprehensive capstone documentation:
1. Problem statement: Post-harvest Kinnow losses in Punjab's citrus belt and supply chain friction.
2. Complete end-to-end system architecture (Web, Mobile, Backend, PostGIS, ML).
3. Data pipelines, transit telemetry models, and cold-chain risk algorithms.
4. Database entity-relationship diagrams (ERD) and API endpoint catalogs.
5. End-to-end testing, integration benchmarks, and validation results.
6. Deployment guides, operational prerequisites, and future scope.
