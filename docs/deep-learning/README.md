# Deep Learning Project Submission

**Title**: Kinnow Quality Classification Using Convolutional Neural Networks

This documentation package contains the academic deliverables for the deep learning component:
1. Dataset source, licensing, and acquisition methodology.
2. Exploratory data analysis, class distribution, and data leak prevention strategy.
3. Baseline CNN architecture and hyperparameters.
4. ResNet18 transfer learning architecture, fine-tuning methodology, and loss formulations.
5. Comparative evaluation results: Accuracy, Precision, Recall, F1-score, and Confusion Matrices.
6. Checkpoint selection, robustness checks, and inference latency benchmarks.
